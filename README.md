# 호야의 ABC 섬

5살 내외 아이를 위한 영어 첫걸음 게임 (단일 HTML · PWA · 로그인 없음).

- 섬 10개 · 놀이 53개: ABC 해변 · IJK 정글 · QRS 바다 · 동물 숲 · 무지개 정원 · 숫자 산 · 냠냠 농장 · 몸 놀이터 · 장난감 마을 · 인사 언덕
- 미니게임: 따라 그리기(대문자 획순) · 풍선 터뜨리기 · 두더지 잡기 · 짝 카드 · 호야에게 주기(끌어서/눌러서) · 듣고 고르기(숫자는 세기) · 첫소리 찾기(파닉스)
- 안내는 한국어 음성, 영어 낱말은 영어 음성. 글을 몰라도 소리와 그림만으로 진행
- 별 1~3개, 놀이마다 스티커, 섬마다 보물 상자와 트로피
- 부모님 화면(곱셈 문제로 잠금): 놀이 시간, 섬별 진도, 헷갈린 단어, 하루 놀이 시간 제한, 영어 천천히, 모든 섬 열기
- 기록은 기기에만 저장 (abc-island-v1)
